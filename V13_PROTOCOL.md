# v13 prospective test

Freeze a storage-only 1,024-slot fp16 trace field. Distances combine root-mean-square appearance and slow sensory context errors, and agent odometry in units of a typical place spacing. No location labels, world tags, actions, rewards from the judge or learned policy enter the store. Start with fixed sensory bandwidths .10 (32 components) and .09 (16 components), spatial bandwidth .65 place spacings. Judge by actual stored identity, with no abstention credit. Compare partitioned cues, context/position ablations and the inherited v11 saturation generator. Dev seeds 26001–26003, sealed 26101–26124. Seal code and harness before using sealed seeds. No tuning on sealed outcomes.

Test 64/128/256/512/1024 places; A (144) then B (144) then A vs an A-only clone, both with and without sleep (relative accuracy >=.8); same-looking places with separated positions, same-looking places across worlds identified only by slow averages of prior different sensory observations, and indistinguishable-history negative control. Test cold anchoring after a translated odometry origin, including ambiguous first sightings, and report steps/errors. Known-vs-new cue rejection: high-confidence wrong/all novel <=.1, novelty AUROC >=.8; report known coverage and accuracy, conditional errors and hard negatives. Sleep on both genuine duplicates and old incidental records, require freed slots and no aggregate accuracy loss on the two learned grids. Compare backward channel values on observed paths with judge-known directions. Fixed checkpoint <=1 MiB, no growing archive. Desktop CPU B=1, GPU B=64 synchronized p95 for cue+write+link after warm-up, include full-store and allocation cases. Target 1 ms/2 ms respectively and 2 s sleep. Laptop hardware, real A2, C1/C7 and S0/S1 require separate runs. If a gate fails, document cause and preregister any change with fresh seeds.

# Mixed grounded and nonspatial experiences
Before implementation and results. One TraceAtlas instance alternates odometry-backed and position-free observations. A missing coordinate must neither create a fake origin nor enable a landmark anchor. Store normalized unlabeled key and prior sensory context under the same byte budget. Hold the apparent cue fixed for paired events; distinguish only by prior observations. Evaluate paired recall with intact vs identical contexts in procedurally generated audio spectra, slowly changing body signals, and symbol-like binary features. Judges know the generator, the organ sees only vectors. Test a time-addressed mixed physical/digital sequence through checkpoint and restore. These are synthetic transfer tests, with no language, human, or real-device performance inference.
